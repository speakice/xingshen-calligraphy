# 行深书法 · 书法学习

一个以「读帖 → 拆解 → 临写 → 盲写」为学习路径的书法练习网页。当前版本以练习功能为主，同时包含书法理论与审美两个内容模块。

## 功能

- **法帖观摩**：在赵孟頫《三门记》、《兰亭序》《多宝塔碑》《九成宫醴泉铭》《洛神赋》之间切换，支持按钮缩放、`⌘ / Ctrl + 滚轮`缩放，以及放大后的拖拽平移。
- **《三门记》原帖扫描**：内置 16 页高清原帖图像，每 4 页无缝拼成一屏，共 4 屏并按传统阅读顺序自右向左排列，可用左右箭头整屏翻阅。
- **固定习字台**：练习页顶部为法帖选择，并可在“观摩 / 技法 / 练习”之间自由切换，桌面端整页无需滚动。
- **单行范字栏**：技法卡片和练习画布下方均提供可横向滚动的单行范字列表；点击“全字库”可打开完整检索面板。
- **《三门记》全字库**：覆盖题目、正文与落款中的全部 332 个不重复字。每个字都有原帖单字图、读音、结构、部首、笔顺、首笔/主笔/折笔/收笔分析和一键临写入口，可按结构筛选，也可按汉字、简体或拼音搜索。
- **技法分析**：可切换任意一个帖中字查看逐字分析；原有「門、之、永、多、泉、神」仍保留手工拆解，“永”字包含完整的永字八法。
- **临写**：左侧约三分之二为练习画布，背景辅助字直接使用右侧范字的原帖单字图；可调节透字清晰度、米字格和笔锋粗细。
- **盲写**：默认隐藏范字，写完后可展开原作对照。
- **砚台悬写**：点击砚台蘸墨后，空中移动不会落墨；在笔画起点停驻约 0.22 秒（或单击）起笔，移动即可运笔，停顿约 0.32 秒（或再单击）自动提笔。点击搁笔台、滚动页面或按 `Esc` 会立即停笔。
- **按住书写**：保留传统 Pointer Events 按压缩放模式，兼容触屏与手写笔。
- **本地保存**：每个范字的临写与盲写练习分别保存在浏览器 `localStorage` 中，刷新或切换页面不会丢失。
- **书法理论**：按笔法、结体、章法、书史筛选文章，并打开完整阅读面板。
- **审美**：通过“中和、气韵、骨力”三个主题，从单字和关系层面训练观察方式。

## 本地运行

```bash
npm install
npm run dev
```

打开终端中显示的本地地址即可。

## 构建

```bash
npm run build
npm run preview
```

## 技术栈

- React 19 + TypeScript
- Vite
- Canvas 2D 墨迹绘制
- Pointer Events
- cnchar 静态生成笔顺与结构数据
- CSS 响应式布局
